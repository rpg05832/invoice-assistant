# הורדת מודלים ובחירה לפי המחשב

במסך **זיהוי וחיבורים** מופיע מדריך הורדות בראש העמוד. הוא מזהה את המעבד, הזיכרון והזיכרון הפנוי במחשב שמריץ את ההתקנה, ומציע מסלול קל, מאוזן או מסלול לניסויים גדולים יותר. ההמלצה היא נקודת התחלה למדידה על המסמכים שלכם, ולא הבטחת דיוק.

1. **כבר כלול במתקין:** Tesseract Fast בעברית ובאנגלית, שני מנועי רצף ספרות קלים, MNIST וכלי אימון הספרות האישי. אפשר להתחיל לעבוד גם בלי הורדת תוספות.
2. **התוספת הראשונה לעברית:** heb_rivok, כ־9MB. מיועד לעברית מודפסת, אנגלית וספרות. אחרי ההורדה בוחרים אותו לעמודים חדשים ובודקים מול דוגמאות שלכם.
3. **השוואה נוספת למלל מודפס:** Tesseract Best, כ־19MB. בוחרים לפי איכות הקריאה וזמן העבודה בפועל.
4. **השוואה לכתב יד מספרי:** במחשב מתאים מתחילים במנוע ראייה אחד, למשל GLM-OCR. המדריך מציג גודל הורדה והתאמה שמרנית לחומרה. חלופות נוספות מופיעות בהרחבה לפי סדר עדיפות.
5. **ניסויים מתקדמים:** Qwen, PaddleOCR-VL, LightOnOCR ו־Indra. המודלים שמסומנים ״ספרות בלבד״ משמשים למספרים. Indra מצריך בדיקת התאמה לתנאי רישיון המודל המוצגים לפני הורדה ובחירה.

אפשר להפעיל מנוע ראייה מקומי אחד בכל פעם. מנועי העברית והספרות הקלים נשארים זמינים לצדו. שמרו תיקונים מאושרים, בדקו את מדדי האיכות ואת תוצאות הבדיקה הנפרדת של האימון האישי, ובחרו לפי המסמכים והכתבים שמגיעים אליכם.

## דירוג לפי משימה ומחשב

| משימה | סדר ניסיון מומלץ | הסיבה |
| --- | --- | --- |
| עברית מודפסת | Fast הכלול → rivok → Best → Indra | התחלה מהירה, תוספות קטנות לעברית, ואז חלופה בעלת רישיון נפרד. משווים את מספר התיקונים ואת זמן הקריאה באותם מסמכים. |
| ספרות בכתב יד | Paddle v6/v5 והמודל האישי הכלולים → GLM-OCR → Qwen3.5 0.8B → חלופות ראייה נוספות | מנוע הרצף קורא מספר שלם; האימון האישי מתאים אותו לדוגמאות ולכתבים שלכם. MNIST הכלול הוא הצעה נוספת לספרות מופרדות. מנועי הראייה מוסיפים השוואה לחיתוכים קשים. |
| הקשר של עמוד | מנועי Tesseract לעבודה שוטפת → Qwen3-VL 4B להשוואת הקשר | מלל בעברית נבדק במנועי העברית. במחשב חזק אפשר להשוות גם הצעות הקשר ולבדוק סדר מילים מול המקור. |

זהו סדר ניסיון לפי תפקיד ועלות הפעלה. דירוג דיוק אישי מבוסס על הדוגמאות שלכם; מסך הלמידה מפריד תוצאות אימון מתוצאות בדיקה על מסמכים נפרדים.

| מחשב | אפשרויות התחלה |
| --- | --- |
| מחשב חלש, 4GB זיכרון או שני מעבדים לוגיים | הכלים הכלולים + rivok ו־Best. המודלים הקטנים עדיפים לעבודה מהירה. |
| 8GB זיכרון, לפחות 3GB פנויים ו־4 מעבדים לוגיים | אפשר לנסות GLM-OCR או Qwen3.5 0.8B, אחד בכל פעם, על חיתוך מספר. |
| 12GB זיכרון, לפחות 5GB פנויים ו־4 מעבדים לוגיים | אפשר להשוות גם PaddleOCR-VL, LightOnOCR ו־Qwen3-VL 2B. |
| 16GB זיכרון ומעלה, לפחות 6GB פנויים ו־4 מעבדים לוגיים | אפשר גם Qwen3-VL 4B להצעות הקשר. |

אלה אומדנים שמרניים לניסוי על מעבד x64, ללא צורך בכרטיס מסך. גודל ההורדה שונה מהזיכרון בזמן עבודה. במדריך שבתוכנה מופיעים הגודל, דרישות המחשב וההתאמה למחשב שמפעיל אותה, לצד כל מודל. מודל ראייה על מעבד עשוי להיות איטי בהרבה ממנועי הבסיס; בדקו קודם דוגמה אחת.

## בדיקת עברית ותיקון בסיס

בראש המדריך מופיע **המצב בפועל** של מנוע העברית ושל קובצי הספרות. הכפתור **בדיקת קריאת עברית** קורא דוגמה מקומית עם המילה ״חשבונית״ ומספר עם אפסים מובילים; הוא אינו פותח חשבונית שלכם. התוצאה מופיעה מיד במדריך.

אם חסרים קבצים, לחצו **בדיקה ותיקון קובצי הבסיס מ־GitHub**. הפעולה מאמתת חתימות ומורידה מחדש רק קבצים חסרים או לא תקינים. אם מנוע ההפעלה עצמו חסר או אינו עולה, התקינו את חבילת Windows המעודכנת. פרטי האבחון נגישים בהרחבה מתחת לכפתורים.

חבילת Windows המעודכנת מפעילה את Tesseract עם נתיבים יחסיים כדי לתמוך בתיקיית משתמש בעברית. אין צורך להתקין Tesseract בנפרד במחשב.

## הורדה דרך GitHub

כל הורדות המודלים בתוך התוכנה משתמשות ב־[עותקים הציבוריים במאגר](https://github.com/rpg05832/invoice-assistant/releases/tag/public-models-v1). ההפניות למקורות המקוריים בתיעוד משמשות לייחוס ולמחקר. ההורדה במוצר אינה נופלת בחזרה ל־Hugging Face.

הקבצים אומתו מול חתימות SHA-256 קבועות של המקורות. קובץ גדול שחולק לחלקים ב־GitHub מורכב מקומית ונבדק שוב בשלמותו. הורדה שנקטעה נשמרת להמשך; קובץ שלא עבר אימות אינו מותקן. כתובות הפניה מחוץ לשרתי GitHub נדחות.

המסמכים, החיתוכים המתוקנים והמשקולות האישיות אינם נשלחים למאגר. העותקים ב־GitHub כוללים רק מודלים ציבוריים, מקורות ופרטי רישוי.

## מה לומד מהתיקונים

אימון הספרות מעדכן מודל אישי קטן המבוסס על מנוע הרצפים. תיקוני ספקים ומלל משמשים להתאמות שמות, כללי רישום ותבניות. משקולות מודלי הבסיס נשארות מקוריות; אין אימון אוטומטי של כל מודלי Qwen, Tesseract או Indra מכל תיקון.

גרסה אישית נבחנת על מסמכים שלא שימשו לאימונה ומושווית למנוע הבסיס לפני הפעלתה להצעות. המנועים הכלליים נותנים מגוון הצעות; המודל האישי מתאים את הקריאה לדוגמאות ולכתבים שלכם. בדיקת המקור והאישור נשארות בידיכם.
