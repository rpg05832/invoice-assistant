# מסמכים, אחסון ומחיקה

## איפה המסמכים נמצאים

בחלון Windows לחצו Win+R, הדביקו `%LOCALAPPDATA%\InvoiceAssistant\data` ולחצו Enter. פרטי המסמכים והמצבים שלהם נמצאים במסד הנתונים `invoices.sqlite3`; עותקי המקור ותמונות העמודים נמצאים תחת `files`. אין להעביר או למחוק קבצים מתוך תיקיית הנתונים ידנית בזמן שהתוכנה פועלת.

אישור מסמך משנה את מצבו ל״מוכן ליצוא״. הוא נשאר באותו מאגר ומופיע במסנן ״מוכנים ליצוא״. לאחר יצוא יש גם צילום נתונים קבוע במנת היצוא; תיעוד הקליטה בחשבשבת הוא שלב נפרד. אישור או הורדת Excel אינם אישור קליטה.

## ארכיון לעומת מחיקה לצמיתות

״לארכיון״ מסתיר את המסמך מהתור הרגיל ומשאיר את הנתונים והקבצים. ניתן לצפות בו במסנן ״ארכיון״.

למחיקה לצמיתות מסמנים מסמכים ברשימה ולוחצים **מחיקה לצמיתות**, או פותחים מסמך ולוחצים על אותו כפתור בתחתיתו. מוצגת תחילה רשימה של כל העמודים, הפיצולים ועמודי ההמשך שיימחקו. המחיקה מתבצעת בקבוצת קובצי מקור מלאה, כדי שלא להשאיר חשבונית המחוברת לעמוד שנמחק. PDF רב־עמודי יכול לכן לכלול יותר רשומות מאלה שסומנו תחילה. יש לסמן את אישור הרשימה וללחוץ על כפתור המחיקה המפורש.

המחיקה מסירה את הרשומות ואת קובצי המקור ותמונות העמודים שהתוכנה שמרה. דוגמאות למידה אישיות וכללי ספקים נשמרים בנפרד. עותקים בגיבויים שנוצרו קודם אינם משתנים. אם Windows מחזיק קובץ פתוח, תופיע הודעה והתוכנה תנסה להשלים את הניקוי בהפעלה הבאה. אין בתוכנה ביטול למחיקה לצמיתות.

קבוצה הכוללת מסמך שתועד במנת יצוא אינה ניתנת למחיקה בדרך זו: תיעוד היצוא והקליטה נשמר. יש לסיים או לעצור אימון פעיל לפני מחיקת מסמכים שלו.

## כפילויות ותיקיות

קובץ זהה מזוהה לפי SHA-256 של הבתים שלו, בנפרד לכל חברה. שינוי שם בלבד אינו מאפשר להעלותו שוב. קובץ שנוצר מחדש יכול להיות בעל תוכן שונה ברמת הבתים, גם אם הוא נראה דומה; קיימות בנוסף בדיקות כפילות חשבונאיות לפי פרטי המסמך. מחיקה לצמיתות מאפשרת להעלות מחדש את המקור שנמחק.

״העלאת תיקייה״ סורקת את הקבצים שנבחרו, כולל תתי־תיקיות שנתקבלו בבחירה, ומעתיקה את המקורות לתוכנה. בגרסה זו אין עדיין חיבור לתיקייה חיצונית ללא העתקת המקורות, ואין מעקב אוטומטי רציף אחרי תיקייה.

## סריקה חוזרת ושדות חסרים

הכפתור **סריקה חוזרת למסמך** מופיע בשורת הפעולות העליונה במסמך. ההשוואה היא לערכים המוצגים בטופס, כולל תיקונים שטרם נשמרו. יוצגו רק הצעות שאינן ריקות ושונות מהערך הקיים; לסכומים נערכת גם השוואה מספרית, כך ש־`100` ו־`100.00` אינם שינוי. אם אין הבדלים ייכתב ״לא נמצאו שינויים בפענוח החוזר״. רק שדות שסומנו והועתקו עוברים לטופס; אישור החשבונית נשאר פעולה נפרדת.

עדכון התוכנה אינו מחליף אוטומטית פענוח שנשמר או תיקונים שעשיתם. במסמכים קיימים יש להשתמש בסריקה חוזרת ולאשר את ההבדלים הרצויים. שם ספק ומספר עוסק יכולים להיקרא מהמקור גם כשאין עדיין כרטיס מתאים ברשימת הספקים של החברה.
