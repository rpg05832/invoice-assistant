# בדיקה מהירה מול המקור

במסך המסמכים לוחצים **בדיקה מהירה**. התור כולל מסמכים שממתינים לבדיקה או נדחו, בהתאם לחיפוש, לסינון ספק/סוג ולבחירה הנוכחית. גם בפתיחת מסמך רגילה מופיע סרגל המעבר.

תמונת המסמך נשארת מול הנתונים. בלשונית **נתונים לתיקון** עורכים את השדות, ובלשונית **טקסט הפענוח** רואים את הטקסט שהמנוע קרא ואת השדות לפני תיקון. בעמודי המשך בוחרים את העמוד הרצוי בתצוגה. שינוי שדה מודגש בצבע ולידו הערך המקורי. התמקדות בשדה מציגה אזור מקור כאשר נשמר לו מיקום.

| פעולה | מקש או כפתור |
|---|---|
| שמירה, אישור והבא שממתין לבדיקה | Enter או ״אישור והבא״ |
| אישור מתוך הערה מרובת שורות | Ctrl + Enter; Enter רגיל מוסיף שורה |
| מעבר לשדה הבא | Tab; חזרה לשדה הקודם עם Shift + Tab |
| הבא בלי אישור | Alt + חץ שמאלה או ״הבא ללא אישור״ |
| הקודם | Alt + חץ ימינה או ״הקודם״ |
| הבא שעדיין ממתין לבדיקה | ״הבא שממתין לבדיקה״ |
| התמקדות בפרט שדורש טיפול | F8 או ״מעבר לשדה לטיפול״ |
| שמירה וחזרה לרשימה | Esc או ״חזרה לרשימה״ |
| זום במקור | כפתורי הגדלה, הקטנה ו״התאם למסך״ |

תיקונים נשמרים לפני מעבר או יציאה מהמסך. מעבר רגיל אינו מאשר חשבונית. חזרה למסמך מאושר בלי לשנותו אינה מחזירה אותו לבדיקה. הזום נשמר לכל מסמך במהלך העבודה הנוכחית.

Enter מפעיל את אותן בדיקות חשבונאיות כמו כפתור האישור. פרטים חסרים, מטבע שלא זוהה, סכומים לא תקינים, צ׳ק שלא אושר או שאלת ספק פתוחה משאירים את החשבונית לטיפול. מטבע חסר אינו הופך לשקל בלי בחירה שלך. אחרי תשובה ראשונה לספק חוזרים לאותה חשבונית ומאשרים אותה במפורש. לחיצה ממושכת או כפולה בזמן שמירה אינה מאשרת כמה חשבוניות ברצף.

בתוך רשימה נפתחת, כפתור או תיבת סימון נשמרת פעולת המקלדת הרגילה שלהם. Enter אינו מאשר בזמן הקלדה מורכבת או כתיבה רגילה בהערה. סרגל ההתקדמות וכפתורי המעבר נשארים גלויים כשגוללים את השדות או את המקור.

## כלי תיקון מהיר

- **לחיצה להעתקה מהמקור:** מתמקדים בשדה, פותחים ״כלי תיקון מהיר״ ומפעילים העתקה מהמקור. מילים ומספרים שיש להם מיקום מודגשים על התמונה. לחיצה מעתיקה את הערך לשדה הפעיל לבדיקה; אין אישור אוטומטי. מעבר לתמונת מקור אחרת מסיר מסגרות שאינן מתאימות לה.
- **מגדלת לשדה הפעיל:** התמקדות בשדה מציגה את אזור המקור שלו כאשר קיים מיקום. גם בחירת מילה במקור מגדילה את האזור שנבחר.
- **בחירת הצעת צ׳ק במקלדת:** לאחר זיהוי באזור מסומן מופיע אזור בחירה עם הצעות ממוספרות. כשהאזור ממוקד, 1–9 בוחרים הצעה. הצ׳ק נשאר לא מאושר עד לסימון ״בדקתי״. הקלדה בתוך שדה מספר ממשיכה להקליד ספרות כרגיל.
- **חיפוש ספק בהקלדה:** שם, קוד או מספר עוסק; חצים לבחירת הצעה ו־Enter לשיוך. פעולה זו אינה מאשרת את החשבונית.
- **מחשבון מע״מ:** בוחרים אם ידוע הסכום לפני מע״מ או הכולל, מזינים סכום ושיעור, ומקבלים חישוב מדויק לשתי ספרות. רק לחיצה על העתקת התוצאה משנה את השדות במסך, לצורך בדיקה.
- **השלמות אישיות:** מגדירים קיצור וטקסט, לכל החברה או לספק מסוים. בהערה מקלידים `;קיצור` ורווח, או בוחרים כפתור השלמה. ההשלמות נשמרות אישית במחשב.
- **השוואה לחשבונית קודמת מהספק:** מציגים שתי תמונות ואת הפרטים החוזרים. אפשר לבחור כללי רישום והערות להעתקה; תאריכים, מספרי חשבונית וסכומים אינם מועתקים עם הכללים.
- **תמונות ממוזערות:** הסרגל מציג תמונות ומספרים של החשבוניות בתור. מעבר ישיר שומר תחילה את התיקונים.

## תורים, תיקון מרוכז והחזרת אישור

ברשימת המסמכים בוחרים תור: כל הממתינים, סכומים, ספקים, צ׳קים, או מסמכים שסומנו לחזרה. **לחזור למסמך הזה** שומר הערה אישית בלי לשנות את נתוני החשבונית. ניתן להסיר את הסימון, ואישור מחודש מסיר אותו מתור החזרה.

בתיקון מרוכז בוחרים מסמכים, שדה וערך ורואים לפני/אחרי. אפשר למלא רק שדות ריקים. התיקון אינו משנה מספרי חשבונית או סכומים, וכל חשבונית ששונתה חוזרת לבדיקה. מסמך נעול או כזה שהשתנה מאז התצוגה המקדימה מחייב בחירה ובדיקה מחדש.

**החזרת אישור אחרון לבדיקה** מציגה תחילה את החשבונית. לאחר בחירה מפורשת היא חוזרת לתור הבדיקה. פעולה זו זמינה לאישור שטרם יוצא; מסמכים יוצאים או שנקלטו נשארים נעולים.

## סביבת עבודה אישית וחזרה למקום האחרון

בוחרים אילו שדות להציג ראשונים ובאיזה סדר, רוחב מקור של 40%, 50% או 60%, גודל אות וקיצורים אישיים. לדוגמה, אפשר לבחור F9 לאישור ו־Page Down למעבר. ההוראות בסרגל מתעדכנות לפי ההעדפה.

**המשך מהמקום שהפסקתי** חוזר לחשבונית, לשדה, ללשונית ולמיקום הגלילה האחרונים, עם הזום שנשמר. תיקונים נשמרים במעבר או בחזרה לרשימה. העדפות, השלמות וסימוני עבודה נשמרים לכל חברה במאגר המקומי, וכלולים בגיבוי המלא של ההתקנה; חבילת התקנה נקייה אינה כוללת אותם.
