# חלון עצמאי ועדכון התוכנה

גרסה 0.2.1 ל־Windows נפתחת בחלון תוכנה עצמאי, ללא כרטיסייה בכרום וללא חלון פקודות. קיצור הדרך הרגיל מפעיל את החלון החדש. סגירתו מסיימת גם את השרת המקומי ואת מנועי העזר שבבעלות התוכנה. אם יש תיקונים שלא נשמרו, תופיע שאלת סגירה.

## מסמכים לאישור

פתיחת מסמך מציגה את העמוד המלא לצד כרטיסי הספק, פרטי החשבונית, הסכומים והצ׳קים. שדות הליבה נראים יחד; פרטים נוספים וכלים מיוחדים נמצאים בהרחבות. הגדלה, מגדלת, סימון אזור, Enter לאישור ומעבר וחזרה למסמך הקודם נשארו זמינים. בחשבוניות עם הרבה פריטים או צ׳קים אפשר להרחיב את הפרטים לפי הצורך.

## עדכון מתוך התוכנה

1. שמרו תיקונים פתוחים וחזרו לרשימה.
2. לחצו בתחתית הצד **גרסה ועדכון התוכנה** ואז **בדיקת עדכון חדש**.
3. אם יש גרסה חדשה, מוצגים מספר הגרסה, גודל הקובץ ופרטי השינוי. לחצו **הורדת העדכון מ־GitHub**.
4. לאחר שהקובץ עבר אימות, לחצו **התקנה והפעלה מחדש**. התוכנה תגבה את מסד הנתונים, תיסגר ותיפתח שוב לאחר ההתקנה. אימון אישי פעיל צריך להסתיים או להיעצר קודם.

הורדות העדכון מגיעות מפרסומי Windows במאגר `rpg05832/invoice-assistant` בלבד. נבדקים גרסה, כתובת הקובץ, גודל וחתימת SHA-256 מול פרטי GitHub וקובץ החתימה. גרסה ישנה וקובץ שלא עבר אימות אינם מותקנים. הבדיקה אינה שולחת מסמכים, תיקונים או מודלים אישיים.

הנתונים נשמרים בתיקיית המשתמש `InvoiceAssistant\data`, מחוץ לתיקיית ההתקנה. גיבויי מסד הנתונים שלפני עדכון נשמרים ב־`data\backups`. המודל האישי, החברות והמסמכים אינם מוחלפים בקובצי ההתקנה. יומן עדכון נשמר בתיקיית `InvoiceAssistant\updates`; יומן הפעלה נשמר ב־`InvoiceAssistant\logs`.

## רכיב החלון

החלון משתמש ב־Microsoft Edge WebView2, בלי לפתוח דפדפן Chrome. המתקין כולל את מתקין WebView2 המקורי והחתום של Microsoft לצורך התקנה גם בלי הורדה נוספת במחשב הלקוח. מנועי ה־OCR הקלים ממשיכים להיות כלולים, והמודלים האופציונליים ממשיכים לרדת מתוך התוכנה דרך GitHub.

לצורכי אבחון ופיתוח בלבד, `--no-browser` מפעיל את השרת בלי חלון ו־`--browser` פותח דפדפן חיצוני. ההפעלה הרגילה של Windows אינה זקוקה לאפשרויות האלה.
